The three options

Option A — AWS DX + GCP Dedicated Interconnect
Customer-owned router in a colo (KINX Gasan / LG U+ Pyeongchon) with cross-connects to both AWS DX and GCP DI. Full control, highest CapEx (router + colo).
Option B — Cross-Cloud Interconnect (CCI)
Google-managed direct link from GCP to AWS DX location. No customer colo needed. GCP CCI port priced higher than DI ($5.60/hr vs $2.328/hr at 10G) but zero hardware/colo footprint.
Option C — HA VPN
IPsec tunnels over public internet. Cheapest fixed cost. Bandwidth scales via multiple tunnels + AWS TGW ECMP. Per-tunnel effective ~1.25 Gbps single-flow. Best for small/medium volumes or immediate deployment.

Transfer time formula

time (hours) = data_TB × 8000 / effective_Gbps / 3600

  • Interconnect (A/B): effective = port_Gbps × link_count × 0.85 (85% efficiency)
  • VPN (C): effective = tunnel_count × 1.25 Gbps (conservative per-tunnel)

Assumptions

  • List price only — no EDP/PPA (AWS), no CUD (GCP), no promotional credits.
  • Both Option A and Option B use AWS Direct Connect Dedicated port.
  • Option A does not include customer router hardware, colo rack/power/cooling, remote hands.
  • Option C effective per-tunnel throughput 1.25 Gbps is a conservative single-flow limit. Real aggregate depends on parallel streams (Storage Transfer Service etc.).
  • AWS DTO applies for A→G direction regardless of port ownership.
  • Volumes convert internally to bytes, then billed per each provider's granularity (AWS decimal GB, GCP binary GiB).
